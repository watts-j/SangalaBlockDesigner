# The Sangala Blocks parts list: every brick in the kit, and the upstream of the .library file.
#
#     python tools/parts_library.py "Projects/Full Parts List.txt"
#
# From Glen's Full_Parts_List.xlsx, 2026-08-27: 73 parts, listed there by both LEGO Design ID and
# LDraw part number. The design number is what a builder ORDERS by and is what each line leads with.
#
# A :kind heading names the bin every part under it belongs to, the label its menu button should
# carry, and where it matters the shape the page must draw it as. The ORDER OF THE SECTIONS IS THE
# ORDER OF THE ROWS in the Library panel, so this file is also how the parts are sorted.
#
# NO QUANTITY AND NO COLOR ON ANY LINE. A library is a catalog of shapes - bins, not stock - so a
# count here would be read as inventory and a color would be read as a decision. Neither is either.
#
# The name, the footprint and the height are read from the LDraw library, never typed here.

# SLOPES THAT TURN A CORNER, falling in two directions instead of one. Named for what they DO
# (Watts, 2026-08-27): "Wedged vs. Sloped is not a clear distinction." It is not - LDraw calls 13548
# a slope and 48933 a wedge, and a student holding the two would be hard put to say which is which.
# They were briefly one Wedge bin, which also swept them in with the wedge PLATES the application
# already offers, and those are a different thing again.
# SPLIT UPRIGHT FROM INVERTED, as Slope and Inverted Slope already are: what a piece rests on is the
# difference that decides where it can go, and it is exactly the difference between these two pairs.
# 13548 rests on its whole 2 x 2 and 3676 on 1 x 1 of the same box; 48933 on its whole 4 x 4 and
# 13349 on 2 x 1 of the same.
# `rect` on both, and deliberately: it asks for no quarter turn, which is right for a piece with no
# single ramp to lay across the profile. Their footprints are not declared at all - they are read off
# their undersides, which is how the two inverted ones come out smaller than the boxes they fill.
:kind slopecorner "Slope Corner" rect
13548                      # Slope 2 x 2 x 1 Corner
48933                      # Slope 4 x 2, Corner

:kind invslopecorner "Inverted Slope Corner" rect
3676                       # Slope, 2 x 2, Corner, Inv.
13349                      # Slope 4 x 2, Corner, Inv.

# A curved slope. MEASURED 2026-08-27 against the full catalog and no longer provisional: 93273 is
# 1 x 4 studs and 2 plates, with its length along the part's own z - the same axis the ramp runs on
# for every 45-degree slope (3040 is 1.00 x 2.00, 3037 is 4.00 x 2.00). So a bow is laid the way a
# slope is: the footprint swaps to put the curve ACROSS the profile, and the part turns to match.
# It took two faults in the measuring tool to see this. The bow first measured 1 x 8 studs and 14.49
# plates, which is why `rect` stood here - a shape that claims nothing was the only safe thing to
# write against a number nobody believed.
# DECLARED `bow`, NOT `slope`. It was `slope` for a day, which bought the swap and the turn and cost
# the drawing: the page draws a slope AS a slope wherever it cannot use the real outline, so a bow
# turned end-on came out a wedge - a glyph for a part with no wedge in it. `bow` turns exactly as a
# slope does and falls back to a plain rounded rectangle, which end-on is the truth.
:kind bow "Bow" bow
93273                      # Plate w. Bow 1 x 4 x 2/3
